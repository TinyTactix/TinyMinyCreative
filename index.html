Frequently Asked Questions

How does the 4-step account creation process work?

You configure your Identity & @StudioHandle, choose Personal/Business and Adult/Child safety tiers, set a strong password with a security recovery question, and verify via a 6-digit email OTP before unlocking the launcher.

How do the GitHub Download buttons work?

Clicking Download .html fetches the standalone HTML file directly from TinyTactix/TinyMinyCreative on GitHub and saves it to your computer, while GitHub Link opens the repository file page.

How does the EasyLearn blue palette work?

EasyLearn uses a dedicated blue study palette (Cobalt Blue or Sky Study) across its launcher card, badges, and interactive controls.
